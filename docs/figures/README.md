# Figures

Generated by `python scripts/make_figures.py` from `HW2/logs/` and `robot_control/config/`.
[`numbers.md`](numbers.md) lists the values behind each figure. No run has a `truth.yaml`, so every
pose below is a filter estimate.

## `trajectories_wide.png` and `trajectories.png`

Landscape and portrait versions of the same figure. The README uses the landscape one.

Estimated robot position for the 7 of 24 runs whose `waypoints.csv` has `reached = 1` at all three
waypoints. Discontinuities are EKF updates from tag looks taken while the robot was stopped. In
`run_20261023_071302` the navigator flagged WP2 reached with the estimate 198.5 cm from the goal.
Commit 9f444fd (`fix mistaken complete`) changed that logic five minutes after the run, going by the
robot clock (inference).

## `waypoint_residuals.png`

Estimate minus goal at each waypoint for the same 7 runs, with the filter's 1σ. The shaded bands are
the configured targets from `nav.yaml`, not achieved values. Filled markers had an accepted tag
update after the waypoint's last primitive (11 of 21 rows). Hollow markers did not (10 of 21), and 8
of those are exactly 0.0 cm because the estimate is the predicted endpoint of the last primitive.
Those zeros carry no accuracy information.

## `observations.png`

Distance against viewing obliquity for 173 of the 184 logged tag observations: 142 accepted, 28
rejected by the chi-square gate, 3 rejected as out of range (values parsed from the logged reason).
The other 11 rejections have no logged geometry: 10 with too few frames and 1 unstable. No
observation exceeded the 60° limit; the largest logged obliquity is 39.9°. Half of the gate
rejections are at the first look from the start pose, where tag 0 read 1.61 to 1.62 m against 1.50 m
in the map. The log cannot separate a tag placement error from a range bias.

## `spin_calibration.png`

Hand-measured turn angle against command duration, by direction and command level, with the linear
fits stored in `study_wood2_hw2_ext.yaml`. Diamonds mark the smallest executable step, evaluated as
in `step_timing.min_amount`. Squares are the 5 logged fine-level spins that ran past the level's
calibrated range; they predate `fine_max_deg`. Requests are plotted at their commanded duration,
which includes `time_scale`, so they sit above the raw fit. The overshoot of these spins was not
logged. The shaded band is the range of spins that currently has no executable level: above
`fine_max_deg`, the fine level is not allowed, and below the coarse minimum, the coarse level cannot
run.
